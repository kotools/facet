# 📖 Glossary

Kotools Facet introduces its own vocabulary for describing the relationship
between a class and its projections. A faceted class declares facets. Each facet
yields one projection.

This page is the canonical reference for that vocabulary. Other documentation
can rely on these terms instead of redefining them.

## 🧩 Terms

- **Faceted class**: a class that declares its own projections.
- **Facet**: a named perspective on a faceted class.
- **Projection**: a class generated from a facet.
- **Faceted property**: a property declared in a faceted class.
- **Projected property**: a property declared in a projection.
